Placeholder Laravel 13 app for [https://shop.troxela.store](https://shop.troxela.store).

অনলাইনে কেনাকাটা — সহজ, নিরাপদ, দ্রুত

Currently a branded "শীঘ্রই আসছে" (coming soon) landing page only. The real app will replace this placeholder later.

- Laravel 13.43.0, PHP 8.3, no Node build, no extra packages
- App name/tagline come from `.env` (`APP_NAME`, `APP_TAGLINE`)
- Shared production `vendor.zip` is uploaded at deploy time (see `~/workspace/troxela-apps/vendor.zip`)
